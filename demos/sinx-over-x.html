넓이가 삼각형 < 부채꼴 < 큰 삼각형 순서라는 건 그림만 봐도 분명합니다. 식으로 쓰면 sin x / 2 < x / 2 < tan x / 2.

각 변을 sin x / 2 로 나누고 뒤집으면 cos x < sin x / x < 1 이 됩니다. x → 0 일 때 왼쪽 cos x 가 1 로 가니, 가운데도 1 로 갈 수밖에 없습니다. 이것이 샌드위치 정리입니다.

x 를 0 으로 보내면서 오른쪽 sin x / x 값이 1 에 다가가는 것을 같이 보세요. 각을 라디안으로 재야 부채꼴 넓이가 x/2 가 된다는 점도 짚어 주시면 좋습니다.
