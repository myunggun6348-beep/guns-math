역함수는 왜 y = x 대칭인가

역함수는 x 와 y 의 역할을 맞바꾼 함수입니다. 점 (a, b) 가 원래 함수 위에 있으면 (b, a) 가 역함수 위에 있습니다. 좌표를 뒤집는 일이 그림에서는 y = x 에 대해 접는 일과 같습니다.

y = x² 을 골라 보세요. 뒤집으면 하나의 x 에 y 가 둘씩 생겨 더 이상 함수가 아닙니다. 그래서 x² 은 x ≥ 0 으로 잘라야만 역함수(√x)가 생깁니다 — 교과서가 '일대일'을 따지는 이유입니다.

y = √x 와 y = x² (x ≥ 0) 을 번갈아 골라 보면, 둘이 서로의 역함수라 같은 그림이 나옵니다.
