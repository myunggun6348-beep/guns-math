## 사용자의 방향

사용자는 대한민국 고등학교 수학 교사이며 경제에도 관심이 있다. 현재 방향은 개인 로그인 중심의 학습 홈페이지다. 로그인 후 자기 학습 기록을 이어가며 반 등록은 필요하지 않다. 공개 자료와 가입 없는 체험 학습은 유지하도록 명시적으로 선택했다. 모바일·태블릿 가독성과 펜 풀이 공간을 중요하게 여긴다. 홈 화면은 복잡해지지 않게 유지한다. 확률과 통계에 국한하지 않고 여러 수학 영역과 오지선다·주관식을 함께 제공한다.

한국어로 전문적이고 친절하게 소통한다. 요청한 기능은 구현·검증·GitHub 반영·배포 확인까지 진행해 왔다. 실제 계정 비밀번호나 인증 정보를 문서에 넣지 않는다. 새 작업의 범위를 벗어나는 배포·메시지 전송 등은 별도 판단한다.

### 가입 후 짧은 학습 진단 — 2026-10-13

가입 완료 창에서 선택적으로 시작하고, 건너뛴 학생과 기존 학생은 홈의 접힌 ‘나의 학습 진단’에서 시작한다. `today.html?diagnostic=1&grade=1&subject=common1`로 기존 문제·수식·펜 풀이 화면을 재사용한다. 학년·과목을 고르고 기존 내장 기초/표준 문항에서 5문항을 선정한다. 개념을 골고루 포함하고 오지선다/주관식을 섞는다. ‘아직 배우지 않았어요’는 오답과 구분하며 진단에서는 힌트를 제공하지 않는다. 문항과 정답은 기존 검증된 데이터를 재사용했다.

진단은 `today-study-records`, 오답노트, 개념 통계, 복습 일정, 연속 학습에 집계하지 않는다. `math-home-profile-v1.diagnostics[track]`에 과목별 최근 진단 결과(학년·완료시각·개념별 정오/미학습)를 보관하고 기존 프로필 동기화로 계정에 연결한다. `LearningDiagnostic.weak`는 해당 개념의 일반 학습 시도가 아직 없을 때만 진단의 재확인 개념을 오늘의 선정에 제공한다. 기존 복습/취약 통계가 우선이며, 당일 완료 문항은 그대로 유지한다. 재진단은 그 과목의 최근 진단만 바꾸고 일반 기록은 보존한다.

진단 임시 풀이는 별도 `diagnostic-학년-과목` 슬롯으로 계정별 저장한다. 홈 이어하기, 입력·편집 가능한 필기·채점 상태 복원, 저장 실패 후 재시도도 지원한다. 임시 풀이/필기는 같은 브라우저에만 보관한다. 기존 계정 분리 보호를 사용하며 실제 학생 계정에 대한 조작은 하지 않았다.

검사: `check-learning-diagnostic.cjs`(전 과목 구성·가입 시작/건너뛰기·320/820/1280px·기존 점수/오답/통계 보존·채점/필기 재접속·저장 실패·프로필 동기화·맞춤 선정·로그아웃 격리), `check-personal-daily.cjs`, `check-study-draft.cjs`, `check-study-sync.cjs`, `check-personal-home.cjs`, `check-home-portal.cjs`, `check-study-resume-ui.cjs`.

### 개인 로그인 중심 홈페이지 — 2026-10-13

로그인 전에는 로그인·회원가입·계정 찾기·자료 둘러보기·체험을 안내한다. 로그인 후에는 자신의 학습 설정·이어하기·맞춤 문제·오답·성장 기록을 표시한다. 계정 확인 중이거나 로컬 기록의 소유자가 로그인 계정과 다르면 이전 기록을 개인 홈에 표시하지 않는다. 반 입력과 표시를 개인 설정/홈에서 제거했고 기존 프로필의 반 값은 보존했다. 선생님 방도 개인 학습 현황을 기본으로 하며 기존 반 분류는 접힌 ‘기존 반 정보로 보기’에서 제공한다. 이를 닫으면 반 필터는 해제된다.

`student-sync.js`는 로그아웃/세션 만료 시 계정별 로컬 보관본을 만든 뒤 체험 기록으로 복원한다. 로그인 시 해당 계정의 보관된 필기를 서버 기록과 병합한다. 체험 보관 키는 `math-student-guest-data-v1`, 명시적 체험 선택은 탭의 `math-home-explore`, 마지막 아이디는 `math-student-last-id-v1`이다. 아이디 복구는 마지막 아이디를 사용자가 버튼을 눌렀을 때만 보여준다. 서버 로그아웃 실패 시 로컬 계정 기록을 바꾸지 않으며, 오래된 로그아웃 응답이 새 로그인을 덮어쓰지 않도록 세대를 대조한다. 기록 분리 실패에는 `canUseLocal`이 기존 노트/통계/오늘 점수의 읽기와 덮어쓰기를 차단한다. 원본 또는 계정별 보관본을 유지하고 저장 공간 오류를 안내한다.

가입 학습 설정은 계정 등록 후 저장해 기존 체험 프로필을 가입자의 이름으로 바꾸지 않는다. 첫 가입은 현재 기기 체험 기록을 계정에 이어 붙인다고 안내하며, 기존 계정 재로그인은 해당 계정 보관본을 우선한다. 공유 디바이스를 통한 UI 노출을 막는 설계이며 로컬 보관본을 암호화한 것은 아니다. 임시 풀이와 필기 이미지의 다른 기기 동기화는 추가하지 않았다.

검사: `check-personal-home.cjs`, `check-study-sync.cjs`(로그아웃·세션 만료·분리 실패·로그아웃 실패·새 로그인 경합), `check-home-portal.cjs`, `check-home-design.cjs`, `check-home-learning.cjs`, `check-home-resume.cjs`, `check-review-growth.cjs`, `check-study-resume-ui.cjs`, `check-admin-students.cjs`, `check-student-reset.cjs`, `check-student-attention.cjs`, `check-weekly-review.cjs`, `check-spaced-review.cjs`.

### 학생·선생님 주간 복습 성과 — 2026-10-13

학생 홈에 접을 수 있는 ‘주간 복습 성과 보기’를 추가했다. 선생님 방 학생별 같은 제목의 분석에서는 서버가 집계한 날짜별·개념별 정답 확인/최종 완료와 오늘 복습/전체 미완료를 보여준다. 관리자 인증을 거친 기존 `/api/student-admin` 응답에 `student.review` 요약만 추가하고 문제 원문·필기·비밀번호는 추가하지 않는다. 비회원 및 아직 동기화하지 않은 기록은 제외한다.

`StudyState.recentReviews`/`reviewSummary`를 브라우저와 서버가 공유한다. 주간 기간은 한국 시간의 오늘을 포함한 7개 날짜(6일 전 00:00부터 현재)로 명시한다. 보관 중인 오답의 마지막 복습 정답만 한 번 집계하고 삭제·재오답·과거 확인 정보 없는 완료 기록·미래 기록은 제외한다. 중복 노트는 최신 변경을 먼저 고르므로 재오답을 과거 정답으로 덮어 집계하지 않는다. 복습 일정·저장 형식·기존 병합은 변경하지 않는다. 현재 집계는 모든 과거 시도/삭제한 성과를 복원하는 이력 분석이 아니다.

검사: `check-weekly-review.cjs`, `check-review-growth.cjs`, `check-admin-students.cjs`, `check-student-attention.cjs`, `check-spaced-review.cjs`, `check-study-sync.cjs`. 학생·선생님 주간 표와 한국시간 경계, 인증·개인별 집계·자료 비노출, PC·모바일 동작을 확인했다.

### 복습 성장 안내 — 2026-10-13

오답 재풀이 정답 결과에 개념·복습 확인 단계·최종 완료 또는 예정일 전 연습 유지 안내를 추가했다. 정답을 맞힌 뒤 자동으로 화면을 닫던 처리를 제거하고 모든 문항에 ‘복습 목록으로’를 제공한다. 틀린 뒤 같은 풀이 창에서 다시 맞힌 경우도 채점 직전 저장 상태를 기준으로 단계를 설명한다. 저장 실패에는 성장 안내를 표시하지 않는다.

`WrongNotes.recentReviews(now)`는 기존 `reviewStage`, `lastReviewAt`, `lastWrongAt`으로 최근 7일의 보관 중인 복습 정답 노트를 반환한다. 기록 시각의 단조 증가 보정 때문에 미래 1초까지 허용하며 더 미래인 기록·초기화된 오답·확인 정보 없는 과거 완료 기록은 제외한다. 홈에 문제별 한 번의 정답 확인 개념 및 최종 완료 개수를 표시한다. 새 저장 데이터나 API는 없으며 삭제 노트·전체 과거 복습 횟수는 집계하지 않는다. 개념 숙달이나 힌트 없이 푼 정답으로 과장하지 않는다.

검사: `check-review-growth.cjs`, `check-spaced-review.cjs`, `check-spaced-review-ui.cjs`, `check-study-sync.cjs`, `check-similar-practice.cjs`, `check-home-learning.cjs`.

### 홈 복습 개수 구분 — 2026-10-13

기존 ‘복습 대기’를 ‘오늘 복습할 문제’(`WrongNotes.count().due`)와 ‘전체 미완료 오답’(`active`)으로 분리했다. 기존 복습 판정 함수를 재사용하며 미래 일정은 전체에만 포함하고 완료한 오답은 둘 다 제외한다. 최근 평균·연속 학습을 포함해 기록 카드 네 개를 PC 한 줄/모바일 두 열로 표시한다. `check-home-learning.cjs`에서 과거 일정·새 오답·미래 일정·완료·0문제 구분을 실제 저장 데이터로 확인한다. `check-home-design.cjs`에서 네 카드의 반응형 배치를 확인한다.

### 홈 오늘의 학습 안내 — 2026-10-13

주요 학습 카드에 개념·추천 이유·예상 시간을 추가했다. 홈에서 `daily-selection.js`, `problem-bank-client.js`를 읽고 실제 오늘의 학습과 같은 공개 문항/선정 기준을 사용한다. 문제은행을 읽는 동안 구체적 안내는 표시하지 않는다. 완료 세트 재풀이·복습 날짜·저장된 풀이에 맞춰 이유를 구분하며 최근 정답률 60% 미만 개념은 기준을 명시한다. 예상 시간은 남은 문항당 약 1분으로 계산한 안내값이며 검증된 소요 시간이 아니다. 채점 완료만 남은 임시 풀이는 결과 확인만 남았다고 표시한다. 첫 방문 미설정 상태에서는 학년을 임의로 추정하지 않는다.

### 로그인 창 아이디·비밀번호 찾기 — 2026-10-13

로그인 화면의 `studentRecovery` 버튼으로 계정 찾기 안내를 제공한다. 사용자가 버튼을 누르면 `math-student-data-owner`의 유효한 마지막 아이디를 표시하고 로그인 칸에 채울 수 있다. 공용 기기의 다른 학생 기록일 가능성을 안내하며, 서버의 계정 검색 API는 만들지 않는다. 기록 없는 경우와 비밀번호 분실은 선생님 확인/초기화를 안내한다. 이는 학생 직접 비밀번호 재설정 기능이 아니다. `check-home-portal.cjs`에서 PC·태블릿·모바일의 기록 없는 경우·저장 아이디 확인·로그인 복귀를 검사한다. 기존 `check-student-reset.cjs`도 확인한다.

### 밝고 단정한 홈 디자인 — 2026-10-13

모바일(650px 이하) 전체 메뉴는 공부하기/찾아보기/즐기기·묻기 그룹을 유지하면서 그룹 안의 링크를 두 열로 배치한다. 메뉴 설명과 중복 안내 문장을 숨기고 제목·화살표가 있는 최소 58px 높이 카드로 정리했다. PC 설명은 유지한다. `check-home-design.cjs`에서 두 열 배치, 8개 메뉴 유지, 터치 크기·가로 넘침과 모바일/PC 설명 노출을 검사한다.

사용자 정정에 따라 전체 메뉴(`details#more`)는 개인 학습 카드 아래에 둔다. 기본 펼침은 유지한다. 개인 학습·가입·이어하기가 먼저 보이고 전체 메뉴가 그 뒤에 오는 DOM 순서를 PC·태블릿·모바일 검사에 포함한다.

사용자 요청으로 홈 ‘이 사이트에 있는 것 전부 보기’의 `details#more`를 기본 펼침(`open`)으로 변경했다. 학생이 직접 접을 수는 있으며, 새로 접속하면 다시 펼쳐진다. `check-home-portal.cjs`의 기본 상태 검사도 갱신했다.

### 풀던 문제 이어하기

2026-10-13 홈 연결 추가: `StudyDraft.list(owner)`가 계정별 유효한 임시 풀이를 최근 저장 순으로 반환한다. 홈은 과목·개념 및 확인 문제의 원래 오답 존재를 검증한 뒤 최신 하나만 기존 주요 버튼에 연결한다. `today.html?...&resume=1`에서 자동 복원 후 URL 표시를 제거하며, 나머지 과목 변경이나 계정 변경에 자동 복원을 반복하지 않는다. 홈 재방문과 다른 탭의 저장 변경도 안내에 반영한다. `check-home-resume.cjs`로 PC·모바일 비회원/개인 홈·직접 복원·계정 분리를 검사했다.

## 세 가지 통합 업그레이드

사용자가 확인 문제 보강·선생님 분석·개인별 학습을 모두 요청하여 진행했다. 확인 문제에 19개 도전 문항을 추가해 총 114문항으로 늘리고, 모든 문항에 세부 유형을 부여했다. 난도 다음에 유형을 선택하며 추천은 원래 유형을 우선한다. 114문항 모두 원문을 제외한 세 난도 대체 문항을 가진다. 유형별로는 특정 난도만 제공할 수 있다.

선생님 방 학생별 분석은 현재 보관한 오답의 원인과 확인 문제 힌트 사용을 보여준다. 반 카드에도 원인·힌트 요약을 표시한다. `StudyState` 기기별 카운터에 `reviewAttempts`, `hintUsed`, `hintSteps`, `soloCorrect`를 더해 정답 시도도 힌트 현황에 포함하고 재전송 중복 없이 합산한다. 새 집계는 이 기능 적용 후의 확인 문제만 포함한다. 오답 재풀이의 기존 `hintsUsed`를 새 확인 문제 사용으로 중복 합산하지 않는다. 과거 전체 힌트 사용률은 복원하지 않는다.

관련 검사: `check-expanded-questions.cjs`, `check-personal-daily.cjs`, `check-similar-practice.cjs`, `check-student-attention.cjs`, `check-admin-students.cjs`, `check-study-sync.cjs`, `check-spaced-review.cjs`.

## 다음 작업 시 주의

- 완료된 기능을 처음부터 다시 만들지 않는다. 현재 코드·Git 상태·관련 호출부를 먼저 확인한다.
