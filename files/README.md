# 여기에 학습지 PDF 를 올립니다

이 폴더는 자료실(`files.html`)이 내려주는 파일들이 사는 곳입니다.

## 올리는 법

1. **이 폴더에서** `Add file` → `Upload files` 를 누르고 PDF 를 끌어다 놓습니다.
2. 맨 아래 `Commit changes` 를 누릅니다.
3. 한 층 위로 나가서 `files.html` 을 열고 연필(✏️)을 누른 다음,
   `const FILES = [` 아래에 한 줄 추가합니다.

```js
{ date: "2026-08-06", subject: "미적분Ⅰ", kind: "학습지",
  title: "미분계수 연습 20제", href: "files/미분계수-연습.pdf" },
```

`href` 의 파일 이름은 방금 올린 파일 이름과 **글자 하나까지 똑같아야** 합니다.

## 파일 이름 짓기

띄어쓰기 대신 붙임표(`-`)를 쓰세요. 띄어쓰기가 들어가면 주소가 깨져서
내려받기가 안 될 수 있습니다.

- 좋음 — `미분계수-연습.pdf`
- 나쁨 — `미분계수 연습.pdf`

## 이 파일은 지워도 되나요

지워도 사이트는 그대로 돌아갑니다. 다만 이 폴더에 파일이 하나도 없으면
폴더 자체가 사라지므로, 첫 PDF 를 올리기 전까지는 두는 편이 좋습니다.
